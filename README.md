# Автоматизация тестирования API

Проект автоматизации тестирования API для сервиса Яндекс самокат.

## Описание

Автотест проверяет основной сценарий:
- Создание заказа
- Получение заказа по трек-номеру
- Проверка кода ответа API

## Структура проекта
project/
│
├── configuration.py # Конфигурация URL и путей API
├── data.py # Тестовые данные
├── sender_stand_request.py # Функции для API запросов
├── test_order_api.py # Автотесты
├── .gitignore # Игнорируемые файлы
├── requirements.txt # Зависимости проекта
└── README.md # Документация проекта
